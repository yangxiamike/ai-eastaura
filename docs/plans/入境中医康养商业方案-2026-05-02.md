# 入境中医康养产品方案

## 1. 基础判断：上海 vs 杭州

| 维度 | 上海 | 杭州 |
|------|------|------|
| 国际航班/入境便利 | 双国际机场，直航覆盖全球 | 萧山机场，国际线少于上海 |
| 中医资源 | 龙华、岳阳、曙光三大三甲中医院，JCI认证 | 方回春堂(1649年)、胡庆余堂(1874年)、浙江中医药大学 |
| 政策支持 | "推动中医药海外发展"宏观导向 | 2025年11月已发布10条官方康养线路+30个体验点 |
| 康养环境 | 都市型，快节奏 | 西湖、龙井、富春江，天然慢节奏 |
| 竞品密度 | 已有 OriEast、China Wellness Tours 等 | 官方推线路但商业化落地少 |
| 入境游客量 | 远超杭州 | 2024年117万人次(+107.8%)，消费8.28亿美元(+138.2%) |

**结论：以杭州为基地。** 上海做入境门户+高端补充（龙华/岳阳/曙光医院重症疑难病），杭州做主产品交付地。上海虹桥到杭州高铁45分钟，联程无障碍。

杭州核心优势：官方已铺好"10+30"的基建（10条线路、30个体验点），但缺少商业化落地产品——这就是机会窗口。

## 2. 市场数据

- 全球康养旅游：~1万亿美元(2025)，CAGR 8-13%，2030年达$2万亿+
- 亚太：$1,570亿(2025)，占全球38.4%，CAGR >7%
- 纯康养旅行(Primary wellness travel)：CAGR 9.83%，增速最快
- 国际康养游客：每次平均花费$1,764，比普通游客高41%
- 美国：占全球康养旅行的20%，占消费的36%
- 杭州入境游客：2024年117万人次(+107.8%)；前三大来源国：美国、马来西亚、韩国；2025年中东海湾国家新增免签后增速明显

## 4. 目标人群

### 画像

> **35-60岁海外亚健康人群** — 这个范围合理，但建议分层：

| 层级 | 年龄段 | 特征 | 支付意愿 | 占比 |
|------|--------|------|---------|------|
| 核心层 | 40-55岁 | 高压职业、睡眠问题、慢性疲劳、更年期前后、轻度代谢问题 | 最高 | ~60% |
| 扩展层 | 35-40岁 | 预防型、皮肤/抗衰、产后调理 | 中高 | ~25% |
| 外围层 | 55-60岁 | 慢性疼痛、术后康复、养生习惯 | 中 | ~15% |

### 来源市场优先级

1. **美国**（全球36%康养消费，杭州最大入境来源）→ 华人+主流
2. **东南亚**（马来西亚已Top2，文化亲近）→ 华人为主
3. **韩国**（杭州Top3来源国，韩医文化亲近）→ 韩国本土人群
4. **中东海湾国家**（2025新增免签，高消费力）→ 新兴市场
5. **欧洲**（德国/法国对自然疗法接受度高）→ 第二梯队

### 核心痛点

- 体检指标"正常"但主观不适（疲劳、失眠、焦虑、消化不良、慢性疼痛）
- 西医无法诊断和治疗的灰色地带
- 对中医有认知但不知道如何找到可靠的服务
- 担心被宰、沟通障碍、卫生条件

## 5. 产品设计

### 产品理念

**"TCM Wellness Check-in"** — 不是旅游，是来"报到"。定位为中医版健康年检+调理套餐。弱化景点打卡，强化身体变化。

### 3天版 — "TCM Reset"（中医重启）

| 时段 | Day 1 | Day 2 | Day 3 |
|------|-------|-------|-------|
| 上午 | 接机+入住精品酒店 | 太极/八段锦晨练 | 太极晨练 |
| | 中医四诊(望闻问切)+体质测评 | 针灸/艾灸调理(第2次) | 个性化中药茶饮配制 |
| 中午 | 药膳午餐 | 药膳午餐 | 药膳午餐 |
| 下午 | 推拿/经络疏通(60min) | 中药熏蒸/药浴 | 中医生活方式工作坊 |
| | | | (居家养生方案+饮食指导) |
| 傍晚 | 自由休息/西湖散步 | 龙井茶园药食同源体验 | 结业问诊+季度远程随访方案 |

**包含：**
- 2晚精品酒店（西湖/龙井周边，非五星但品质对标国际精品酒店）
- 6餐药膳
- 2次针灸/艾灸调理
- 1次推拿/经络疏通
- 1次中药熏蒸/药浴
- 1次中医生活方式工作坊
- 全程英文翻译+健康管家
- 个性化居家调理方案（电子版+纸质版）
- 季度远程随访×1次

### 5天版 — "TCM Rebalance"（中医再平衡）

在3天版基础上增加：

| 新增内容 | Day 3-5 |
|---------|---------|
| 深度调理 | +2次针灸/艾灸、+1次拔罐/刮痧 |
| 专项模块(三选一) | A. 睡眠调理 / B. 肠胃调理 / C. 疼痛管理 |
| 功法深化 | 站桩/五禽戏入门教学 |
| 药食手作 | 亲手制作个性化中药茶包/膏方 |
| 心理调适 | 中医情志养生session(结合现代正念技术) |
| 长效方案 | 3个月远程随访(每2周1次在线问诊) |

**包含3天版全部 + 深度调理 + 专项模块 + 药食手作 + 3个月远程随访**

## 6. 合作模式

### 核心合作：杭州老字号中医馆

**首选：方回春堂（河坊街馆）**

理由：
- 始创1649年，376年历史，品牌可信度极高
- 5000㎡明清建筑，本身就是体验点
- 已入选杭州30个中医药体验点
- 国药馆+国医馆一体，药材质量可控
- 河坊街是杭州核心旅游区，散客自然流量高

**次选：胡庆余堂**

理由：1874年红顶商人胡雪岩创办，"江南药王"，品牌辨识度高

**合作模式：**
- 非股权合作，采用**服务采购+品牌联名**
- 中医馆提供：诊室场地、执证中医师、药材/制剂
- 我方提供：海外客源、全程英文服务、产品设计、品牌营销
- 收入分成：中医馆拿诊疗服务费（固定费率），我方拿打包溢价

### 辅助合作：精品酒店

- 优先选择西湖西线/龙井/灵隐周边的50-100间规模精品酒店
- 要求：安静、有花园/庭院、可提供药膳定制

### 人才：健康管家

- 核心岗位，中医+英文双通
- 可招募浙江中医药大学留学生(目前已有大量海外中医留学生)
- 或中医药大学英语专业毕业生
- 1名管家服务4-6位客人

## 8. Go-to-Market

### Phase 1：验证期（前3个月）

- **渠道：** 海外华人社群(小红书海外版、北美华人论坛、微信公众号)→ 这批人对中医有认知基础，转化率高
- **KOL试体验：** 邀请3-5位海外健康/生活方式博主免费体验，换内容
- **产品：** 仅开3天版，每月2个团(每团4-6人)，先跑通流程
- **目标：** 服务30-50人，收集NPS和评价，打磨SOP

### Phase 2：扩展期（3-12个月）

- **渠道扩展：** 
  - 上线国际康养旅游平台(bookretreats.com、Tripaneer)
  - 与海外企业HR部门合作"高管健康假"(Executive Wellness Leave)
  - 与海外高端健身房/瑜伽馆交叉推广
- **产品：** 同时开放3天和5天版，增加专项模块选择
- **目标市场：** 美国西海岸(直飞杭州经停或上海转)、东南亚华人、韩国

### Phase 3：规模化（12个月后）

- 多城市复制：成都、昆明
- 开发"企业康养通道"(Corporate Wellness Channel)
- 建立自有中医康养评估体系和品牌标准

## 9. 风险与应对

| 风险 | 应对 |
|------|------|
| 中医馆服务质量不稳定 | 固定合作医师(不超过3人)、建立SOP评估表、客人评价驱动医师选择 |
| 外国人中医接受度有限 | 强调"体验"而非"治疗"、避免苦药汤(用药膳/茶饮/外治法为主) |
| 药材/食品安全 | 只用方回春堂自营药材、药膳食材可溯源 |
| 签证/入境政策变动 | 关注240小时过境免签(已有54国)、杭州144小时免签 |
| 管家人才短缺 | 与浙江中医药大学建立实习合作、建立培训体系 |

## 10. 为什么现在行动

1. **杭州官方10+30基建已就绪**，但商业化处于真空期——先发优势窗口
2. **中国入境游正在爆发前夜**，2024杭州入境+107.8%，免签持续扩大
3. **全球康养旅游向"纯康养"转型**，Primary wellness travel增速最快(9.83%)
4. **短期产品供给为零**，3-5天产品是市场空白
5. **中医国际形象正在升级**，WHO将中医纳入ICD-11，海外的中医认知从"替代"走向"补充+主流"
