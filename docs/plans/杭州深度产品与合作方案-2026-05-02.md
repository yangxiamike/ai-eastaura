## 一、官方"10+30"的真正价值

杭州2025年9月/11月由文旅局+卫健委联合发布30个中医药体验点+10条康养线路。核心判断：

**30个体验点的价值：供应商资质预审。** 政府帮你筛过一轮——有资质的医馆、有药膳能力的餐厅、有康复环境的住宿。不用自己从零踩点验证。

**10条线路的价值：几乎没有。** 那是文旅局给国内大众旅游做的半日-3天观光产品，面向飞猪用户。和我们没关系。

我们要用的不是线路，是场馆。

## 二、产品骨架

不是旅游线路。是**以方回春堂为服务交付中心的中医康养调理程序**。3天和5天两档。

### 3天版 — TCM Reset（¥12,000 / $1,680）

```
Day 1  抵达 → 入住精品酒店 → 浙江中医药博物馆轻量入门（理解中医是什么）
Day 2  晨练（八段锦/太极）→ 方回春堂：中医四诊+体质评估 →
       第一次调理（针灸/推拿，60min）→ 胡庆余堂药膳午餐 →
       第二次调理（艾灸/经络疏通）→ 龙井低强度恢复活动
Day 3  晨练 → 第三次调理 → 中医生活方式指导 → 带走版Wellness Summary →
       居家执行方案 + 远程随访预约 → 返程
```

### 5天版 — TCM Rebalance（¥21,000 / $2,880）

```
Day 1-2  同3天版
Day 3    复诊微调 → 第四次调理 → 专项模块（睡眠/肠胃/压力 三选一）
Day 4    转场桐庐 → 江南养生文化村 → 第五次调理 →
         药食手作（配制个人中药茶包）→ 自然环境恢复
Day 5    晨练 → 最终评估 → Wellness Summary → 3个月远程随访方案 → 返程
```

### 核心结构：评估 → 干预 → 带走方案

- **评估层**：中医四诊+体质测评+主诉基线（睡眠/压力/疲劳/肩颈自评量表）
- **干预层**：5-6次调理（针灸/推拿/艾灸/拔罐，按需组合），药膳每日供给，功法晨练
- **带走层**：英文Wellness Summary + 14天/3个月远程随访 + 个人化居家方案

不包含：国际机票/签证/保险/处方药/额外医疗检查

## 三、合作模式

### 方回春堂：服务采购 + 品牌联名

- 中医馆提供：固定时段诊室 + 2-3位固定执证中医师 + 药材
- Eastaura提供：海外客源、英文管家、产品设计、获客营销
- 结算：中医馆按次收固定诊疗费（¥300-500/次），Eastaura拿打包溢价
- 联名：对外标注"调理服务由方回春堂（est. 1649）提供"

不搞股权、不搞独家、不让医馆直接对客（管家层隔离）。

### 其他合作

- 胡庆余堂药膳馆：固定套餐协议价，减少点餐决策
- 精品酒店：西湖西线/龙井/灵隐50-100间规模，协议价，每次按团预订
- 江南养生文化村：按团预订住宿+晨练+药膳打包
- 浙江中医药大学：留学生→健康管家人才管道

### 健康管家（关键角色）

中医基础+英文流利，1人服务4-6客。来源：浙江中医药大学留学生（母语英文+学过中医）。
