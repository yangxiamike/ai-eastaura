# Eastaura 后台指挥台 UI 样板图归档

归档日期：2026-04-27

本目录保存当前阶段生成的后台指挥台 UI 样板图，用于后续产品设计、前端开发和视觉风格对齐。

## 样板图清单

1. `docs/assets/workbench-ui/01-cold-start-dashboard.png`
   - 冷启动总览
   - 用于展示每天最重要的线索、内容、审核和 AI 建议。

2. `docs/assets/workbench-ui/02-content-studio.png`
   - 内容工作台
   - 用于管理选题、脚本草稿、待审核内容和内容状态。

3. `docs/assets/workbench-ui/03-pov-video-generator.png`
   - POV 短视频生成器
   - 用于生成体验型短视频脚本、镜头提示词和合规检查。

4. `docs/assets/workbench-ui/04-publishing-calendar.png`
   - 发布日历
   - 用于安排 Reels、TikTok、Shorts、LinkedIn 和 Newsletter 发布节奏。

5. `docs/assets/workbench-ui/05-lead-attribution.png`
   - 线索归因
   - 用于查看内容从曝光、点击到 Intake 提交和视频咨询的转化。

6. `docs/assets/workbench-ui/06-lead-detail.png`
   - 客户线索详情
   - 用于查看单个 lead 的 Intake 摘要、AI 评分、风险提示和下一步动作。

## 设计判断

第一版后台指挥台应优先围绕冷启动内容获客建设，而不是先做完整行程运营系统。

优先级：

```text
内容生产
-> 内容发布
-> 内容归因
-> Lead 筛选
-> AI 辅助跟进
```

等有真实付费客户后，再加强资源库、Trips 行程交付和复购模块。
